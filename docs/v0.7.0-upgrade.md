# SuperAgent v0.7.0 upgrade

`ModelClient` implementations must return one additional `ModelUsage` value
from `Complete` and `Summarize`. Existing `ModelReply` values do not change.
Adapters without exact usage may return `ModelUsage{}`; such providers cannot be
used with `WithModelHooks` in this release.

Applications may opt into durable admission and usage synchronization with
`WithModelHooks`. Both hooks are required when the option is non-nil. After hooks
must be idempotent by the supplied stable call ID.

OpenAI now explicitly sends `store=true` by default for both Complete and
Summarize. Set `OpenAIClientConfig.DisableModelResponseStore` or the standalone
process environment variable `OPENAI_DISABLE_MODEL_RESPONSE_STORE=true` to send
`store=false`.
